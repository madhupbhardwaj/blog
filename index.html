Connect your GitHub repository

Your posts live as Markdown files in a GitHub repository. Fill in the details below — the site will fetch and display them automatically.

How to set up your GitHub repository:
1. Create a public GitHub repository (e.g. my-blog)
2. Inside it, create a folder called posts/
3. Add Markdown files — one per post. Name them like my-first-post.md
4. At the top of each file, add frontmatter like this:

---
title: My First Post
date: 2026-10-16
tags: writing, ideas
excerpt: A short description shown on the home page.
---

Then write your post in Markdown below the ---.
Every time you push a new file, it appears here instantly. No build step needed.
